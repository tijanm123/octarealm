# OctaRealm

OctaRealm is a futuristic UFC fight analysis web app that displays upcoming fight cards and generates AI-style predictions based on fighter statistics.

The goal of the project is to provide a clean, game-style interface where users can explore upcoming fights, compare fighters, and view probability-based predictions.

---

## Features

* Live upcoming UFC events
* Fight card visualization
* AI-style prediction system
* Probability bars for each fighter
* Predicted winner indicator
* Mobile-friendly responsive design
* Futuristic dashboard UI
* Auto-refresh fight data

---

## How It Works

OctaRealm analyzes available fighter statistics such as:

* Win/Loss record
* Experience level
* Fight history
* Finishing rate
* Recent performance

Using these inputs, the app calculates a **probability score** and predicts:

* Most likely winner
* Estimated win probability
* Possible method of victory

This is **not betting advice**, but a statistical model for entertainment and analysis.
